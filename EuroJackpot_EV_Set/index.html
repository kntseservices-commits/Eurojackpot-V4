One URL per line — every line is polled in parallel and merged into the archive. Accepts an array of draws, or an object with a draws, results, data, items or content array. OPAP's { last, active } shape and winningNumbers.list are handled natively.

Eurojackpot is not on OPAP's API, and the Nordic operators that publish it send no CORS headers — so it ships bundled inside this file as embedded:ej (also written out as ./eurojackpot.json), rebuilt from Veikkaus draw results. Point a preset at your own proxy if you need it live.
